Реалтайм-скринер USDT-перпетуалов для фьючерсной торговли. Полностью статический сайт —
все данные берутся напрямую с публичных API бирж из браузера, без собственного бэкенда,
без сборки и без зависимостей на этапе разработки.

## Возможности

- **Таблица скринера**: цена (live), изменения за 1м / 5м / 15м / 1ч / 24ч, объём 24ч,
  всплеск объёма (Vol ×), волатильность NATR, фандинг с обратным отсчётом, открытый интерес
  и его изменение за 15 минут, ликвидации за 5 минут, спарклайн за 2 часа. Липкие колонки
  ★/Пара, сортировка по любой колонке, поиск, фильтр по объёму, избранное (localStorage).
- **Режим «Графики»**: сетка из 12 живых свечных графиков с реальной историей (180 свечей),
  таймфреймы 1м–1д, зум и прокрутка в каждой ячейке, пагинация.
- **Карта плотностей**: сканер стаканов топ-40 пар находит аномально крупные лимитные заявки
  (кратно больше среднего уровня, до 5% от цены); близкие плотности подсвечиваются. Стены
  выбранной пары рисуются прямо на графике (кнопка «≡ Стены»).
- **Большой график**: свечи + объём, таймфреймы 1м–1д, live-обновление, полноэкранный режим
  (кнопка ⛶ или двойной клик по строке таблицы), водяной знак тикера, диапазон 24ч в шапке.
- **Инструменты рисования**: трендовая линия, луч, горизонтальный уровень, зона (прямоугольник),
  уровни Фибоначчи. Построения можно выделять, перетаскивать (целиком или за якоря) и удалять
  (Del); сохраняются в localStorage отдельно для каждой пары и переживают смену таймфрейма.
- **Сигналы**: пампы/дампы (1м, 5м), всплески объёма, крупные ликвидации — со звуком (опционально).
- **Лента ликвидаций** и суммарные ликвидации лонгов/шортов за 5 минут в шапке, Σ объём рынка.

## Индикаторы и торговые стратегии

Меню «ƒ Индикаторы» — в стиле LuxAlgo / Smart Money Concepts:

| Индикатор | Что делает |
|---|---|
| ⭐ **RSI-2 Стратегия** | Larry Connors mean-reversion: вход по RSI(2) в экстремуме + фильтр тренда SMA200, TP/SL по ATR. Высокий винрейт, малый тейк. |
| ⭐ **Squeeze Breakout** | По мотивам TTM Squeeze: сжатие Bollinger внутри Keltner + пробой на всплеске объёма. RR ≈ 1:4, низкий винрейт, большой тейк. |
| ⭐ **Smart Signals** | ATR-трейл + сигналы разворота с оценкой силы 1–4 по конфлюенсу (EMA200 / RSI / объём). |
| ⭐ **HyperWave + Money Flow** | Осциллятор импульса с сигнальной линией, гистограмма денежного потока (MFI), точки разворота. |
| ⭐ **Дивергенции (авто)** | Бычьи/медвежьи расхождения цены и RSI по пивотам — линии и метки на графике. |
| EMA 20/50/200, Bollinger Bands, VWAP | Классические скользящие средние и полосы волатильности. |
| Supertrend, RSI, MACD | Тренд-следящий индикатор и осцилляторы в отдельных панелях. |
| Fair Value Gaps, Order Blocks, BOS/CHoCH | Разметка Smart Money Concepts: имбалансы, ордер-блоки, слом структуры рынка. |

**Живой бектест.** У RSI-2 и Squeeze Breakout есть встроенный бектест: стратегия честно
прогоняется по всей загруженной истории текущей монеты и таймфрейма, а бейдж над графиком
показывает реальные число сделок, винрейт, профит-фактор, итог в R и точку безубытка. Цифры
не зашиты — они пересчитываются на лету и меняются от пары к паре и таймфрейма к таймфрейму.
Это два стратегии с противоположными профилями риска: RSI-2 выигрывает часто, но понемногу;
Squeeze Breakout выигрывает редко, но много (RR 1:4 означает, что для прибыли достаточно
выигрывать ~20% сделок).

> Инструмент не даёт финансовых гарантий и не является инвестиционной рекомендацией.
> Бектест на истории не гарантирует результат в будущем.

## Источники данных и устойчивость

| Источник | Что берём |
|---|---|
| Binance USDT-M Futures WebSocket (`!ticker@arr`, `!markPrice@arr`, `!forceOrder@arr`) | тикеры, фандинг, ликвидации |
| Binance REST (`/fapi/v1/*`, `/futures/data/*`) | история свечей, открытый интерес, стаканы |
| Bybit v5 (`/v5/market/*`, public linear WS) | полный автофолбэк, если Binance недоступен |

Если WebSocket Binance молчит (гео-ограничения), приложение само переходит на REST-опрос
(тикеры каждые 3с), а ликвидации подхватывает с Bybit. Если Binance недоступен целиком —
автоматическое переключение на Bybit. Биржу можно выбрать вручную в шапке.

## Структура проекта

```
pulse/
├── index.html              разметка страницы
├── assets/
│   ├── css/style.css       вся тема оформления
│   └── js/
│       ├── app.js          точка входа, циклы обновления, сигналы, UI
│       ├── adapters.js      адаптеры Binance / Bybit (REST + WebSocket)
│       ├── store.js         состояние приложения, метрики, ликвидации
│       ├── table.js         таблица скринера
│       ├── grid.js          сетка живых графиков
│       ├── chart.js         большой график, таймфреймы, полноэкранный режим
│       ├── draw.js          слой рисования (трендовые, уровни, Фибоначчи)
│       ├── indicators.js    индикаторы и торговые стратегии + бектест
│       ├── density.js       карта плотностей (сканер стаканов)
│       ├── config.js        настройки, localStorage-обёртка
│       └── util.js          форматирование, DOM-хелперы
└── README.md
```

## Запуск локально

Любой статический сервер, например:

```bash
python3 -m http.server 8899
# открыть http://localhost:8899
```
