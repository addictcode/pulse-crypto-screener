## Правила для исполнителя

Действуют все правила из `docs/PLAN.md`, плюс:

- **Своя ветка и PR на каждую задачу.** В `main` не пушить и не мержить, мержит владелец.
  Задачи 2–8 — ветки от `integration/phase1`, PR в неё же, пока она не смержена.
- **Коммиты и PR по-русски**, автор — владелец. В коммитах и описаниях PR нет
  `Co-Authored-By`, «Generated by/with Claude Code» и ссылок на сессию; если облако добавляет их
  само — убрать перед созданием PR и после каждой правки описания.
- **Перед коммитом** — сборка и тесты задетых частей, CI в PR зелёный.
- **Строки интерфейса** — с переводом в `web/src/locale-ru.ts`.
- **Свечи из облака** — только архив `data.binance.vision` / S3-бакет (`fapi.binance.com`
  отвечает 451).
- **Честность:** только реальные данные, никаких обещаний прибыли, «Не финансовый совет».
  По итогам B4 сигналы не предсказывают направление — Pulse «видит рынок», а не угадывает его.
