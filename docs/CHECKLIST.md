# Чек-лист перед роликом и деплоем

15 минут на **настоящем телефоне**, после `deploy/home.sh deploy` (или деплоя на сервер) и перед
публикацией ролика. Автоматика (`npm run e2e`, обход стека `npm run stack`, снимки, axe) ловит
почти всё, но не то, что ниже: ей не доступны настоящий телефон, сотовая сеть, TikTok, уведомления
системы и Telegram.

Отмечай прямо здесь, в копии для своего прогона, или в заметке: дата, телефон, браузер, что
было не так.

## 1. Лендинг из ссылки TikTok (3 мин)

Почему руками: встроенный браузер TikTok — не Chrome и не Safari. В нём свои шрифты, свой
масштаб, свои ограничения на WebGL и `localStorage`, а эмулятор его не повторяет.

- [ ] Открыть ссылку из профиля TikTok (`…/?utm_source=tiktok`) **в самом приложении TikTok**:
      постоянная ссылка перенаправила на живой сайт, а не на демо (если туннель или сервер живы).
- [ ] Первый экран: заголовок, кнопки, числа «пар в работе» и «стаканы» появились за пару секунд;
      ничего не ездит вбок, когда ведёшь пальцем.
- [ ] Планета крутится и не тормозит прокрутку; на старом телефоне — хотя бы не роняет вкладку.
- [ ] Переключатель языка: тап раскрывает список, выбор языка переводит страницу.
- [ ] Через минуту в боте `/visits` заход посчитан с источником `tiktok`.

## 2. Игра до конца (4 мин)

Почему руками: проверка «приятно ли» и «понятно ли без подсказки» — не тест.

- [ ] `/play/` из лендинга: десять раундов подряд, выбор вверх/вниз пальцем.
- [ ] Ответ показывается сразу, свечи читаются, кнопки не прячутся под пальцем и под панелью
      браузера внизу экрана.
- [ ] Итог: число угаданных, «Поделиться» открывает системное меню (или копирует ссылку).
- [ ] Нигде нет обещаний прибыли и «точности», есть «Не финансовый совет».

## 3. Терминал (3 мин)

Почему руками: сотовая сеть рвётся и меняет адрес, чего нет у стенда в Docker; живой Binance
ведёт себя не как `FakeExchange`.

- [ ] `/app/` с телефона: лента или терминал открылись, числа живые (меняются).
- [ ] Выбрать пару из списка: график, стены, ликвидации на месте.
- [ ] Выключить и включить мобильные данные (или перейти Wi-Fi → LTE): данные вернулись сами,
      без перезагрузки, и пока их нет — это видно, а не выглядит «спокойным рынком».
- [ ] Свернуть браузер на 2 минуты и вернуться: стрим переподключился.

## 4. Пуш (2 мин)

Почему руками: системные уведомления в headless-браузере не показываются, а на iPhone пуши
работают только у сайта, добавленного на экран «Домой».

- [ ] Включить уведомления о сигналах в настройках терминала (если ключи VAPID заданы).
- [ ] Дождаться сигнала по выбранной паре (взять оживлённую, из пресета «Движение»):
      уведомление пришло, тап открывает нужную пару.
- [ ] Выключить — больше не приходят.

## 5. Бот (2 мин)

Почему руками: настоящий Telegram, токен и аккаунт есть только у владельца.

- [ ] `/start` в боте: ответ на нужном языке, кнопки работают.
- [ ] Кнопка «Терминал» / «Сайт» из бота открывает живой сайт, переход посчитан в `/visits`
      с источником `telegram`.
- [ ] Если включён канал — последний пост выглядит нормально, ссылки рабочие.

## 6. Напоследок (1 мин)

- [ ] `docker compose logs backend --since 15m | grep -iE "error|exception"` — ничего нового.
- [ ] Сводка ошибок браузера (`client_error`, README «Ошибки браузера с прода») — нет свежих
      после деплоя.
- [ ] Записать, что нашлось: если это можно поймать тестом — завести задачу на тест.

Не финансовый совет.
