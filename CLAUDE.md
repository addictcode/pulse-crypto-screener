# Pulse — с чего начать

Скринер крипто-фьючерсов Binance: таблица рынка, график, плотности стакана, сигналы (пампы, дампы,
объём, OI, фандинг, ликвидации, стены), Telegram-бот и канал, генератор вертикальных роликов для
TikTok. Личный проект студента БГУИР (владелец — Дмитрий), идёт к публичному запуску: бесплатно,
продвижение через TikTok, позже — монетизация через Telegram Stars.

Этот файл — входная точка для новой сессии Claude Code. Подробности — в `README.md`; планы и их
статус — в `docs/PLAN.md` … `docs/PLAN-4.md` (сделанное отмечено), **текущий — `docs/PLAN-5.md`**
(фазы 0–7: сеть безопасности, честность, ценность, запас на наплыв, контент, качество).

## Как общаться с владельцем

- По-русски, на «ты», без воды: сначала результат, потом коротко «почему».
- Владелец — джун в Java/Spring: новый паттерн или приём объяснять в 2–3 предложениях.
- Очевидное делать без вопросов; спрашивать, только когда решение действительно за ним.
- Если просьба — плохая идея или есть способ лучше, сказать прямо.
- Вкусовые вещи (шрифт, цвет) — показывать 3–4 реальных варианта картинкой, а не угадывать.

## Жёсткие правила

- **Автор коммитов — только владелец.** Никаких `Co-Authored-By`, «Generated with/by Claude Code»
  и ссылок на сессию — ни в коммитах, ни в описаниях PR. Облачные сессии дописывают это сами:
  проверять и убирать (`gh pr edit`).
- Коммиты по-русски, в стиле `git log`: заголовок — что изменилось, тело — почему.
- Перед коммитом — сборка и тесты задетого: `cd backend && ./gradlew build`,
  `cd web && npm test && npx tsc --noEmit && npm run e2e`, `cd video && npm test && npx tsc --noEmit`.
- Изменения — через ветку и PR; мержит владелец или Claude по его прямой команде.
- Честность в продукте и контенте: только реальные данные, никаких обещаний прибыли и «сигналов,
  которые угадывают рынок», везде «Не финансовый совет».
- Перед удалением данных из живой базы — дамп (`~/Backups/pulse/`).

## Как это работает сейчас

- Живой стек — Docker на маке владельца (`deploy/home.sh`), публичный адрес — Cloudflare quick
  tunnel, постоянная ссылка — GitHub Pages (`index.html` в корне), которая перенаправляет на
  туннель или на демо. LaunchAgent `dev.pulse.home` держит туннель живым. Облачные сессии этот
  стек не видят: деплой, миграции и база — только локально.
- Деплой с мака — одной командой `deploy/home.sh deploy`: поднимает базу, снимает дамп в
  `~/Backups/pulse/`, собирает оба образа из закоммиченного (`git archive`, незакоммиченные правки
  в образ не попадают), перезапускает и проверяет здоровье бэкенда, Liquibase и сайт.
- Telegram-бот, канал, сводка `/digest`, премиум — в коде, но выключены переменными в `.env`, пока
  владелец не создаст бота и канал (README, раздел «Telegram-бот»).

## Что важно знать (выучено на ошибках)

- **Склейка кадров стрима.** До 31.10.2026 после переподключения к Binance два сокета писали в один
  буфер, и цена одной монеты попадала в другую: ~68% пампов и дампов в базе были ложными.
  Исправлено в `BinanceStreamConnection`; история до исправления удалена (миграции 008–009).
  Любые события для роликов всё равно сверяются со свечами.
- **Сигналы не прогноз** (`research/`): через час цена шла в сторону сигнала в 44–48% случаев.
  Позиционирование — «Pulse видит рынок», а не «предсказывает». Что честно можно говорить: после
  сигнала час по паре размашистее обычного (×1.3–2.4, `oi-funding-2026-11.md`) — «где рынок
  проснулся», без «куда». В архивных метках OI возможен заглядывающий вперёд сдвиг до 5 минут. Правила сигналов без нового
  исследования не менять и не подгонять под историю.
- **Binance из США отвечает 451.** Облаку — только архив `data.binance.vision` / его S3-бакет.
- **Рендер роликов — в одну вкладку Chrome** (`CONCURRENCY=1`) с проверкой `video/scripts/check.py`:
  при нескольких вкладках появлялись битые кадры-«плитки».
- **CLS лендинга:** анимации появления только через `transform`, не через свойство `translate` —
  иначе Chrome считает каждый кадр сдвигом страницы (было 0.71 на телефоне). e2e это стережёт.
- **Рисование на графике** проверять мышью на deviceScaleFactor 2 и кликами между свечами.
- Встроенный браузер Claude, когда панель скрыта, останавливает CSS-анимации и rAF: пустой
  лендинг на скриншоте — не баг, проверять в настоящем Chrome.
- **Вёрстку проверять на телефоне 320, 360 и 390 px на всех языках страницы.** 9.11.2026 после
  F4 (четыре языка) шапка лендинга не влезла в телефон, и страница ездила вбок, хотя все 104 e2e
  были зелёными: они идут на поддельном бэкенде и вёрстку не меряют. Стережёт
  `e2e/phone-layout.e2e.ts`; настоящий стек обходит браузером фаза 0 `PLAN-5`.
- Playwright не может скачать свой браузер в этой сети: e2e локально гонять на установленном Chrome
  (`channel: 'chrome'` через временную обёртку конфига рядом с `playwright.config.ts`).

## Решения владельца

- Дизайн: тёмный, без цветного акцента (белый — «выделено», цвет только у роста/падения);
  шрифты Unbounded (заголовки) и Onest (текст); на лендинге — планета.
- Ролики анонимные: без тикеров, дат и времени — постятся позже в любом порядке. Вспышки на
  склейках оставить. Трендовый звук не вшивать (ставится в TikTok); свои эффекты — по флагу `--sfx`.
- Авторизацию на сайте не делать; при монетизации — вход через Telegram, оплата Telegram Stars.
- Свой движок графиков (KLineChart) — отложен, низкий приоритет.
- Языки: терминал — только EN и RU; испанский и турецкий — лишь у публичных страниц (лендинг,
  игра, `/record/`), переводы черновые до вычитки носителем (решение 9.11.2026).

## Что дальше

1. **Владелец:** создать бота (@BotFather) и канал, заполнить `PULSE_TELEGRAM_*` в `.env` (по шагам —
   README, «Запуск на живом стеке»; для всех бот открывается только `PULSE_TELEGRAM_OPEN=true`);
   проверка на healthchecks.io → `PULSE_HEARTBEAT_URL`.
2. **Переезд на сервер** до публикации роликов — `deploy/oracle/README.md`; затем секреты
   `VPS_HOST`, `VPS_SSH_KEY`, `VPS_KNOWN_HOSTS` в GitHub, и CI деплоит сам. Перенос базы с мака
   и постоянной ссылки — шаг 9 там же; дампы и пинг healthchecks.io сервер делает сам (cron).
3. **Контент:** серия про 60 тысяч сигналов с голосом владельца (`video/out/series/*/voiceover.md`
   после рендера) + фоновые ролики по `schedule.csv`, 1–2 в день. Ссылка в профиле — с меткой:
   `https://addictcode.github.io/pulse-crypto-screener/?utm_source=tiktok` (иначе `/visits` не
   отличит TikTok от прочего).
4. Через 2–3 недели чистых данных — повторить исследование сигналов на живой статистике:
   `python3 research/live.py --docker pulse-postgres-1`.
